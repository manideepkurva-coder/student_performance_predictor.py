# Student Performance Predictor 🤖📊

## About the Project

Student Performance Predictor is a Machine Learning project that predicts a student's final score using study hours, attendance percentage, and previous score.

This project was created as the final AI & ML project for the Codomax Digital Internship.

## Features

- Student performance prediction
- Machine Learning model using Random Forest Regression
- Study hours as an input
- Attendance percentage as an input
- Previous score as an input
- Predicted final score
- Performance level classification
- Model evaluation using MAE and R2 Score

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest Regression

## Machine Learning Workflow

1. Created a sample student dataset.
2. Prepared features and target values.
3. Split the dataset into training and testing data.
4. Trained a Random Forest Regression model.
5. Tested the model using test data.
6. Evaluated the model using MAE and R2 Score.
7. Accepted new student information.
8. Predicted the student's final score.
9. Classified the performance level.

## How to Run

Install the required libraries:

    pip install pandas scikit-learn

Run the Python program:

    python student_performance_predictor.py

The program will ask for:

- Study hours
- Attendance percentage
- Previous score

It will then predict the final score and display the performance level.

## Example

Input:

- Study hours: 7
- Attendance: 90%
- Previous score: 75

The program generates a predicted final score and performance level.
